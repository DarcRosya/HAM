how to setup:

1. Make .env file in server/ directory with all needed variables
2. Return to the root folder
3. Install and open Docker Desktop (maybe need to configure the database or smth)
4. Run : "npm run setup". Wait till db starts and will be ready
5. Run : "npm run server"
6. Open another console and run "npm run client"
7. Use link to open our game in browser!
8. Enjoy! You know how to start checking - just be you!
